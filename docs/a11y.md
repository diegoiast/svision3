# Accessibility (A11y) - Widget ID Support

Adding widget IDs to svision3 enables accessibility APIs, testing, automation, and our declarative UI API.

## 1. Add ID to Widget class (`include/svision3/widget.hpp`)

Add to the `Widget` class:

```cpp
// Around line 80, add after is_visible()

virtual Widget &set_id(std::string id);
virtual std::string const &id() const { return id_; }
```

Add to protected section (around line 157):

```cpp
std::string id_;
```

## 2. Implement in `src/svision3/widget.cpp`

```cpp
auto Widget::set_id(std::string id) -> Widget& {
    id_ = std::move(id);
    return *this;
}
```

## 3. Add Fluent support for chaining

In `include/svision3/widget.hpp`, the Widget class already uses Fluent. Ensure `set_id` returns `Widget&`:

```cpp
virtual Widget &set_id(std::string id);
```

This enables: `widget->set_id("volume")->set_enabled(true);`

## 4. Update demo2.cpp to use IDs

Replace the manual widget creation with ID-based approach:

### Before (manual):
```cpp
auto volume_label = std::make_unique<svision3::Label>("50%");
auto* volume_label_ptr = volume_label.get();

auto volume_slider = std::make_unique<svision3::Slider>();
volume_slider->set_range(0, 100);
volume_slider->set_value(50);
volume_slider->set_on_change([volume_label_ptr](svision3::Slider&, float v) {
    volume_label_ptr->set_text(fmt::format("{:.0f}%", v));
});

// Add both via std::move
.add(std::move(volume_slider))
.add(std::move(volume_label))
```

### After (with IDs):
```cpp
.add(ui::label("50%").id("volume_label"))

.add(ui::slider(50, 0, 100)
    .id("volume")
    .on_change([](float v) {
        auto* label = svision3::Widget::find_by_id("volume_label");
        if (label) {
            label->set_text(fmt::format("{:.0f}%", v));
        }
    }))
```

## 5. Add static lookup method (optional, in widget.hpp)

```cpp
// Add to Widget class, around line 26
static Widget* find_by_id(std::string_view id);
```

Implementation in `src/svision3/widget.cpp`:
```cpp
Widget* Widget::find_by_id(std::string_view id) {
    // This requires a way to iterate all widgets
    // For now, can be implemented via Window or a global registry
    // A simpler approach: each Window maintains an id->widget map
    return nullptr;

```

## Summary

| File | Change |
|------|--------|
| `include/svision3/widget.hpp` | Add `set_id()` method and `id_` member |
| `src/svision3/widget.cpp` | Implement `set_id()` |
| `demo/demo2.cpp` | Use `.id()` and `Widget::find_by_id()` for cross-widget callbacks |

## Benefits

1. **Accessibility** - Screen readers can identify widgets by ID
2. **Testing** - Find widgets by ID in tests
3. **Automation** - UI automation tools can target widgets
4. **Declarative API** - Widgets can reference each other by ID
