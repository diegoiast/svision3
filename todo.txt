GUI Toolkit – Task List

Core Architecture
-----------------
[x] Cross-platform GUI toolkit in C++20
[x] macOS backend (Cocoa/CoreGraphics)
[x] Linux backend (X11/Wayland)
[x] Windows backend (Win32)
[x] PIMPL for Window and Application
[x] PIMPL for platform headers (X11, Win32 text rasterizer)
[x] CMake build system
[x] Conan package manager (cairo, spdlog)
[x] Cairo 2D drawing abstraction (Painter)
[x] High DPI / fractional scaling (all platforms)
[ ] OpenGL rendering backend on Linux/Windows (still blurry).
[ ] Cairo+OpenGL on Linux gives blury fonts.
[ ] OpenGL uses cairo for painting text.
[ ] Command interfaces for menus/toolbars and app shortcuts.
[ ] Backends have open/cairo/whatevre backed in. We need to separate them.
[ ] Paintings inside widgets should start at (0,0) not position at window.
